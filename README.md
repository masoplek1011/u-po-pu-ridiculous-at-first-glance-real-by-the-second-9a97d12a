Entry for the make.fun bounty
[Ridiculous at First Glance, Real by the Second](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a)
($2 USDC escrowed).

The program writes a single startup pitch — one sentence, at most 200
characters — to `entry.txt` in the output directory. The pitch sells
vacuum-sealed toast crusts left on celebrities' plates, by the gram, to
superfans: ridiculous until you remember that memorabilia collectors already
pay absurd prices for anything a star has touched.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes a single sentence to `/tmp/out/entry.txt`. The program is
deterministic: every run produces byte-identical output. It uses only the
Node.js standard library and makes no network requests.
